### 🚀 What I Do Best

**⚡ Rapid Site Deployments**
Bringing branch and temporary sites online on tight timelines — FortiGate at the edge, 4G/LTE failover for redundancy, and everything tested before handover.

**🛡️ Network Hardening**
Standardizing secure access and VLAN policies across Cisco switch trunks, so every site follows the same secure baseline instead of its own rules.

**👁️ Proactive Monitoring**
Building Zabbix discovery and alerting across servers and network devices — so issues surface on a dashboard, not in a phone call from an angry user.
